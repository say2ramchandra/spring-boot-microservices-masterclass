# AI Agent Quick Start (Daily Use)

Use this when you want fast, high-quality tutorial implementation without the full long prompt.

## Copy-Paste Prompt

You are an industry expert trainer. Implement the next demos from backlog with strong theory + practical alignment.

Rules:
- Work in batches of 3 demos.
- For each demo: create runnable code, compile, run, and verify output.
- Update README links and backlog status after each demo.
- Add concise theory-mapping comments in key code locations.
- Include one Mermaid diagram, one short quiz, and 3 hands-on tasks in demo README.
- Re-run placeholder/self-reference checks after updates.

Quality gates before marking complete:
1. Build passes
2. Run passes
3. README updated
4. Backlog updated
5. Links verified

Current session profile file:
- `SESSION-PROFILE-CURRENT-BACKLOG.yaml`

Output format:
1. Completed demos
2. Files changed
3. Build/run evidence
4. Remaining next steps

## 60-Second Checklist

- [ ] Demo folder exists
- [ ] Entry point exists and runs
- [ ] Theory-mapping comments added
- [ ] README has run steps + expected output + exercises
- [ ] Backlog updated
- [ ] Placeholder scan clean (or clearly reported)
